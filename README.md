# CloseIt

CloseIt is a lightweight Windows utility designed to help users close applications that continue running in the system tray after their windows are closed.

### Features
- Background monitoring for selected applications
- Steam and Discord support
- Configurable app monitoring
- System tray menu
- Attempts graceful closure without force-killing processes
- Designed as a standalone Windows executable

### Status
**Early development.** Features and compatibility are still being tested.

### Note
Some applications may ignore normal close requests, so complete closure is not guaranteed in every case.
